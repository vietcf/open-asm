# Custom CSS

File CSS chung cho toàn bộ ứng dụng Open ASM.

## Nội dung
- Select2 multi-select styling
- Form styling và centering
- Button container styling  
- Navbar styling
- Responsive design

## Sử dụng
Được include trong tất cả layouts:
```html
<link rel="stylesheet" href="/css/custom.css">
```

## Lợi ích
- Tái sử dụng được ở nhiều layouts
- Style đồng nhất toàn app
- Dễ maintain và update
