📋 MÔ TẢ APP-CONTENT-HEADER - ADMINLTE 4
==========================================

🎯 MỤC ĐÍCH:
app-content-header là phần header của nội dung chính, chứa:
- Tiêu đề trang (Page Title)
- Breadcrumb navigation
- Các thông tin meta của trang

🏗️ CẤU TRÚC HTML:
┌─────────────────────────────────────────────────────────────┐
│ <div class="app-content-header">                            │
│   <div class="container-fluid">                             │
│     <div class="row">                                       │
│       <div class="col-sm-6">                                │
│         <h3 class="mb-0">Page Title</h3>                    │
│       </div>                                                │
│       <div class="col-sm-6">                                │
│         <ol class="breadcrumb float-sm-end">                │
│           <li class="breadcrumb-item"><a href="/">Home</a>  │
│           <li class="breadcrumb-item active">Current</li>   │
│         </ol>                                               │
│       </div>                                                │
│     </div>                                                  │
│   </div>                                                    │
│ </div>                                                      │
└─────────────────────────────────────────────────────────────┘

🎨 CSS CLASSES:

1️⃣ APP-CONTENT-HEADER:
   • Vị trí: Ngay dưới header chính
   • Màu nền: Trong suốt (transparent)
   • Padding: 0.75rem 1rem
   • Margin: 0 0 1rem 0
   • Border: Không có
   • Z-index: 10

2️⃣ CONTAINER-FLUID:
   • Width: 100%
   • Max-width: Không giới hạn
   • Padding: 0 15px (Bootstrap default)

3️⃣ ROW:
   • Display: flex
   • Flex-wrap: wrap
   • Margin: 0 -15px

4️⃣ COL-SM-6:
   • Width: 50% trên desktop
   • Width: 100% trên mobile
   • Padding: 0 15px

5️⃣ PAGE TITLE (H3):
   • Font-size: 1.75rem
   • Font-weight: 600
   • Color: #212529
   • Margin-bottom: 0

6️⃣ BREADCRUMB:
   • Float: right trên desktop
   • Display: block trên mobile
   • Background: #f8f9fa
   • Border: 1px solid #dee2e6
   • Border-radius: 0.375rem
   • Padding: 0.75rem 1rem

7️⃣ BREADCRUMB-ITEM:
   • Color: #6c757d
   • Font-weight: 500
   • Font-size: 0.9rem

8️⃣ BREADCRUMB-ITEM ACTIVE:
   • Color: #495057
   • Font-weight: 600
